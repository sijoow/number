# 하온이의 숫자놀이

4살 아이를 위한 집에서 쓰는 숫자 놀이 앱. 형제 앱 「하온이의 한글나라」(`Desktop/todo`)와 같은 화면 틀·목소리·로그인을 쓰고, **로그인 계정과 아이 정보·설정은 한글나라에서 받아온다**(같은 MongoDB, 한글나라 DB 는 읽기만).
과정은 업체(토도수학) 나이대별 과정의 학습 목표 순서를 따른다 — 레벨 A(유아) A1~A10 → 레벨 B(유치원 기초) B1~B10, 20장 × 5일 = 100일. 그림은 넘버블럭스 친구들(집에서만 쓰는 앱, `refs/` 인물구성도 기준).

## 실행

```bash
npm install
npm run dev          # http://localhost:6300
npm test             # 과정표·판 만들기·진도·스케줄·한글나라 값·로그인 검사
npm run voice:lines  # 들려줄 말 목록 → scripts/voice-lines.json
npm run voice:reuse  # 한글나라에 이미 구운 같은 말 빌려 오기 (크레딧 안 씀)
npm run voice:make -- --voice sua          # 남은 말 견적만 (--yes 를 붙이면 굽는다 · 안전선 19만 자에서 멈춤)
npm run voice:timing # 구운 음성마다 말소리 구간 → src/content/voice-timing.json (노래방 읽기)
npm run image:list   # 힉스필드로 만들 그림 목록 → scripts/image-list.json
npm run image:prompts                     # 그림마다 프롬프트·레퍼런스 → scripts/image-prompts.json
npm run image:install -- drafts/<날짜>     # 힉스필드 결과(results.json) 내려받기 → public/img WebP + image-manifest(?v=내용 해시)
npm run image:upload                      # public/img → 회사 Cafe24 /app/img/lsh/num/
```

`.env.example` 을 `.env.local` 로 복사해 채운다 — 값은 한글나라와 같고 `MONGO_DB=haonnumber` · `HANGUL_DB=todohangul` · `CAFE24_UPLOAD_DIR=/app/img/lsh/num/` 만 다르다.
Vercel 환경변수: `MONGODB_URI` · `MONGO_DB` · `HANGUL_DB` · `ACCOUNTS` · `AUTH_SECRET` · `CAFE24_PUBLIC_BASE_URL` · `CAFE24_UPLOAD_DIR` (그림 주소는 빌드 때 정해지니 값을 넣고 다시 배포).

## 한글나라에서 받아오는 것 (2026-10-27 사용자 결정 — 같은 MongoDB 직접)

| 무엇 | 어디서 | 숫자놀이에서 |
|---|---|---|
| 로그인 계정 | `ACCOUNTS`(같은 값) + 한글나라 DB `users` | 같은 아이디·비밀번호로 들어온다. 계정 만들기·비밀번호는 한글나라 관리자 페이지에서 |
| 공부하는 요일 · 성우 | 한글나라 DB `progress.<아이디>.settings` | 그대로 따른다(바꾸는 곳은 한글나라 부모 페이지). 기기에 받아 두고 켤 때마다 새로 받는다 — `lib/family` |
| 화면 방향 | 한글나라 DB `progress.<아이디>.settings` | 숫자놀이 부모 페이지 「프로그램 관리 → 화면 보기」에서 세로/가로를 따로 정하면 그 값(숫자놀이 `settings.orientation`, 아이디마다 서버 저장). 안 정했으면 한글나라 값 — `lib/orientation` |
| 아이 이름 · 얼굴 | `curriculum/child.ts`(이하온·하온아·하온이) · 한글나라 Cafe24 `child:face` | 같은 파일·같은 그림 주소 |
| 한글나라 시작한 날 | `settings.startOn` 또는 `progress.firstOn` | 부모 페이지에 보여 주기만 — 숫자놀이 '온 지 며칠째'는 숫자놀이를 처음 한 날부터 |

숫자놀이 진도는 **다른 DB**(`MONGO_DB`, 기본 `haonnumber`)의 `progress` 에 쓴다. 두 DB 이름이 같으면 한글나라 진도를 덮어쓸 수 있어서 서버가 멈춘다(`lib/db.ts`).

## 놀이 24가지 (`src/components/play/activities`)

숫자 친구 만나기 · 하나씩 세기 · 몇 개일까? · 숫자 찾기 · 블록 쌓기 · 숫자 쓰기(따라 쓰기 — 노란 펜 머리에서 획 길을 따라서만 칠해짐, 옆에 그 수만큼 점) · 짝짝 손뼉 · 더 많은 쪽(물건·숫자) · 다음 숫자 · 모양 찾기 · 규칙 찾기 · 모아 보기 · 크기 비교(A9) · 더하기(B5) · 빼기(B7) · 모양 나누기(B9).

업체 유아 단계 놀이 8가지(2026-10-28, 판 규칙은 `lib/rounds.ts` + 테스트). 끌어 놓는 놀이는 4살 손을 생각해 눌러도 된다(`play/dragPick`):

| 놀이 | 하는 법 | 업체 놀이 |
|---|---|---|
| 수 세기 기초 | 처음 나오는 날은 하나, 둘, 셋… 판마다 하나씩 늘어나는 물건을 한 줄로, 그다음(`mix`)은 섞인 수가 무리 지어(2×2, 3×2…) — 세고 숫자 카드 둘 중에(카드 위에 그 수만큼 점) | 수 세기 기초(업체도 첫 섬만 차례로) |
| 짝 연결하기 | 위·아래 줄의 짝을 끌어서 선으로 잇기(같은 물건 / 숫자와 점). 첫 판은 곧은 선, 다음 판은 섞여 엇갈림. 위·아래를 차례로 눌러도 이어짐 | 짝 연결하기 |
| 작은 농장 | 「시작」→ 병아리가 하나씩 헛간으로 → "헛간에 몇 마리 있을까?" 카드 둘(병아리 그림, 0 이면 빈 카드) → 맞으면 헛간 앞판이 들리며 하나, 둘 세어 보여 주고 병아리가 걸어 나감 | 작은 농장 |
| 숫자 퍼즐 | 나무판 칸마다 탈리 막대(다섯째는 비스듬히), 아래 빈 칸에 숫자 타일 끌어 넣기(셋씩 나옴) | 숫자 퍼즐 |
| 도형 맞추기 | 흩어진 모양 카드에서 크기·색이 달라도 같은 모양끼리 짝 — 짝이 맞으면 판이 어두워지고 둘만 반짝 사라짐 | 도형 맞추기 |
| 주사위 찾기 | "셋!" 눈이 그 수인 주사위를 칸에 끌어 넣기, 작은 수부터(6까지) | 도미노 산수 |
| 가게 놀이 | 오늘의 놀이(레벨 A, `ask: "name"`): 숫자 친구 손님이 "딸기를 주세요!" → 선반의 서로 다른 물건 셋 중 그것을 바구니에, 넣으면 바로 다음 손님(다섯). 놀이터: "사과 세 개 주세요!" 수만큼 담고 「다 담았어!」 — 많다·모자라다·다른 물건을 알려 줌 | 동물 마트(레벨 A 는 그대로, 2026-10-29) |
| 수직선 밝히기 | "1 + ? = 3" 블록 막대(1~4칸)를 0~10 수직선에 놓고 ✓, 맞으면 판이 밝아지며 블록이 반짝 | 수직선 밝히기 |

맞히면 큰 별이 톡 나와 날아가고(`lib/stars`), 놀이 하나가 끝나면 **「성공!」 창**에 맞힌 수만큼 별이 차오른 뒤 「완료」(5초면 저절로 다음) — 업체 정답·성공 반응처럼.

놀이 화면 공통(2026-10-29 사용자: 업체 놀이 느낌으로): 놀이마다 처음 1.5초 **이름 카드**(큰 그림 + 이름, `SessionScreen` TitleCard) · 위에 **문제 진행 ●→★**(`lib/steps` + `StepDots` — 보기 놀이는 `useChoice`가, 나머지는 놀이마다 `useStep` 한 줄) · 끌어 놓는 놀이 첫 판에 **손가락 시범**(`HandHint` — 집을 곳에서 놓을 곳으로 되풀이, 화면을 만지면 멈춤: 짝 연결·숫자 퍼즐·도형 맞추기·주사위·가게·수직선(+✓ 단추)). 판·물건 크기도 키움(수 세기 기초·주사위·작은 농장).
새 놀이 넷도 놀이터에 있다(과정에서 처음 나온 날부터 열림, 2026-10-27 카드 장면 생성). 놀이 아이콘은 `icon:play:<놀이>`(오늘의 놀이 순서 표시·놀이터 제목) — 같은 뜻 그림이 이미 있는 놀이(만나기·몇 개일까·블록 쌓기·숫자 쓰기·손뼉)는 그 그림(`lib/assets` UI_ART).
보기를 누르면 이름("셋")을 먼저 읽고 딩동댕/땡, 정답은 칭찬을 끝까지 듣고 넘어간다(한글나라 `lib/answer` 그대로). 문제는 시작할 때 섞는다(`lib/rounds.ts`, 순수 함수 + 테스트).

## 숫자 놀이 — 오리지널 게임 (`src/components/games`, 2026-10-27 사용자: "너랑 나랑 만든 오리지널 숫자 게임")

놀이 방식은 우리가 정했다 — 토도수학 자유 모드·사고력 게임이나 넘버블럭스 공식 앱 게임을 옮기지 않는다. 판 만들기·규칙은 순수 함수(`lib/originals.ts`, `lib/yut.ts`) + 테스트.

| 게임 | 하는 법 | 익히는 것 |
|---|---|---|
| 주사위 윷놀이 | 몇 명이서(둘이·셋이 — 혼자는 상대가 없어 뺐다) → **컴퓨터랑**(스스로 굴림) 또는 **친구랑**(사람이 직접 — 이름: 엄마·아빠·언니·오빠·누나·형·할머니·할아버지 또는 직접 쓰기) → 저마다 숫자 친구 고르기(십까지). 「주사위 굴리기」→ 큰 주사위가 하늘에서 쿵 떨어져 도로로로 구르다 멈추고 나온 수를 크게("6 여섯!"). 반짝이는 칸을 하나씩 누르며 "한 칸, 두 칸". 윷판 그대로 모서리·가운데에 딱 멈추면 지름길, 다른 말 칸에 멈추면 잡기(그 말은 처음부터 다시 출발, 잡은 쪽은 한 번 더), 6 도 한 번 더 | 주사위 눈 · 한 칸씩 세기 · 차례 |
