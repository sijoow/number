## 5. 넘버블럭스 그림

- 사용자에게서 **참고 그림(인물도)** 을 받아 `refs/` 에 두고, 이름·모습은 그 그림 그대로. **직접 그리지 말 것** — 한글나라에서 SVG 로 페파를 그렸다가 "너무 달라, refs 그대로 써"라는 지적을 받았다. 잘라 쓰거나 힉스필드 생성의 레퍼런스로.
- 숫자 = 그 숫자만큼 블록인 친구라, 캐릭터 자체가 수 세기 교구(예: "셋" = 블록 3개 친구). 오늘의 모험·세기 놀이의 그림 칸에 그대로 쓰면 좋다.
- 색·모양·이름(한국어로 부를지 원어 이름인지)은 참고 그림을 보고 사용자에게 확인.

## 6. 정해야 할 것 / 제안

- **숫자 읽는 법**(자료에 없음) — 제안: 물건 셀 때 "하나, 둘, 셋", 숫자 이름은 "삼, 셋"처럼 둘 다. 사용자 확인 필요.
- **하루 분량** — 한글나라 규칙(오늘의 모험 = 활동 5개 안팎 + 5일째 확인 놀이, 미달이면 복습)을 따르자고 제안. 스테이지 1개 = 장 1개(5일)로 매핑하면 레벨 A = 50일.
- 첫 범위 = **레벨 A**(10 스테이지). 재사용할 활동: 방울 터뜨리기(숫자 방울), 듣고 고르기("셋! 어디 있을까?"), 똑같은 것 찾기, 쏙 넣기(수만큼 모인 그림에 숫자 넣기), 따라 쓰기(0~9), **짝짝 손뼉(N번 치기 = 세기)**. 새로 필요: 하나씩 눌러 세기, 주어진 수만큼 놓기, 도형 고르기, AB 패턴 완성, 크기 비교.

## 7. 사용자 선호·운영 규칙 (꼭 지킬 것)

- **유료 생성은 먼저 물어보기**: 힉스필드·이미지 API 는 실행 전 **장수와 크레딧을 말하고 "생성해" 확인**을 받는다(한 장도 예외 없음). 물어보고 답을 안 기다리면 안 물어본 것.
- **힉스필드 = 회사 계정**: 생성이 끝나면 바로 전부 내려받고 사용자에게 "다운받았어요, 힉스필드에서 지워도 돼요"라고만 알린다(사용자가 직접 지움). 배치마다 임시 프로젝트를 만들어 담았다.
- 힉스필드 요령: GPT Image 2.5 · medium · 1k 투명 0.5크레딧 / 2k 불투명 1크레딧. 투명 배경은 가끔 둘레가 번지거나(단단한 부분 2px 밖 알파 제거로 해결) 몸통에 구멍이 남(흰 바탕으로 다시 뽑고 바깥 흰색 제거). 생성 후 어두운 바탕 모음 한 장으로 꼭 확인.
- **Typecast**: 보이스동화(Desktop\Dong)와 같은 키·크레딧. 스크립트 안전선 19만 자(`TYPECAST_SAFE_LIMIT`). 사용자가 한도를 8,000자 늘려 줬다(10-26) — 19만을 넘겨 구울 땐 보이스동화 앱 자체의 19만 잠금도 올렸는지 확인하고 `TYPECAST_SAFE_LIMIT` 를 올린다. 한글나라 시점 사용량 ≈ 189,800.
- **화면 시험**: 헤드리스 크롬(CDP)으로 찍되 **`/api/progress` 는 Fetch 로 막는다** — 안 막으면 fe 의 실제 서버 기록(놀이 시간 등)이 바뀐다. 아래 도구 참고.
- 비밀값(.env) 출력 금지 · 다른 프로젝트 .env 는 지시 없으면 열지 않기 · 커밋·푸시는 시킬 때만 · 운영 데이터를 바꾸는 시험은 미리 알리기 · 짧고 모호한 지시는 한 줄 확인.
- 사용자는 화면을 직접 폰으로 테스트하며 스크린숏으로 피드백한다. 지금은 **폰 테스트 중**, 나중에 태블릿 최적화가 목표.
