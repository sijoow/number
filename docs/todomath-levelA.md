### 활동 공통 틀
- 맨 위 띠: ← · 이동 경로 "오늘의 모험 › 활동 이름" · 문제 진행 표시(점 = 남은 문제, ★ = 맞힌 문제).

진행 구조: 업체 = 오늘의 목표 셋(모험 게임 3 · 미션 게임 3 · 사고력 게임 1) + 레벨 지도(섬 11개) + 섬 끝 몬스터 퀴즈 → 새 몬스터 → 콜렉션, 하루 제한 없음.
우리 = 오늘의 미션 셋(오늘의 놀이 · 복습 놀이 · 생각 놀이 1) + **모험 지도**(장 = 섬, 5일 = 섬 안의 길) + 5일째 도장 놀이 → 새 숫자 친구 → 앨범, 하루 제한 없음(부모가 켜면 하루 한 판).
업체 화면·섬 구성을 그대로 옮기지는 않는다 — 방식·리듬은 따르고 화면·묶음은 우리 것(2026-10-29 사용자 "유도리 있게").

## 6. 아직 볼 것

- 섬 별 칸의 아이템이 무엇에 쓰이는지, 레벨 A 뒷섬(A7~A10)의 놀이 구성

## 7. 녹화에서 옮긴 새 놀이 (2026-10-29)

사용자가 고른 것: 몇이랑 몇?(탈리 연구실) · 하나 더 하나 덜(탈리) · 알 속 숫자(뛰어 세기) · 숨은 친구 수직선(탈리를 잡아라) · 열 칸 채우기 → 열(과일 가게) · 생각 놀이 둘(순서 기억하기 · 매트릭스) + 「보여 줬던 애들 다 가능하면」 → 식사 시간 · 숫자 열차 · 로켓 발사 · 숫자 판(백 칸 퀴즈를 1~20 으로).
흐름(무엇을 보고 무엇을 누르는지)만 따르고 그림·말·묶음은 우리 것 — 친구는 넘버블록스 친구 그림, 물건은 단순한 SVG.
